## Ключевые цифры

- Мировая медиана госрасходов на психическое здоровье — **$2,69 на человека в год** (WHO Atlas 2024)
- Доля бюджетов здравоохранения — **2%**, без изменений с 2017 года
- Разрыв между богатыми и бедными странами — **$65 против $0,04** (1 625 раз)
- Россия 2023: **147 больниц, 122 537 коек, 12 297 психиатров**; суицид 21,8 → 8,3 (2011–2024)
- Цена койко-дня в РФ: **1 100–4 840 ₽**
